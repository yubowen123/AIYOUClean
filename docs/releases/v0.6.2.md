# AIYOUClean v0.6.2

第一版公开仓库发布，应用版本 0.6.2 / build 10。

部分清理后保留检查结果：成功项从原 SQLite 索引移除，失败与未处理项继续显示；保留范围、筛选、排序与页码，末页越界才回退。可以继续处理下一批，无需重新扫描。

- 全盘智能检查：启动磁盘与已挂载本地数据盘，区分可处理、只读和访问问题。
- 检测切页继续，同一应用实例同时一项重操作。
- 结果落盘、200 项分页、1 MiB 分块哈希，不因旧扫描数量/时间阈值停止正常扫描。
- 本地整理、查重、空间导航、应用关联文件、隐私与维护功能；可选外部 ClamAV。
- 本次补充公开功能边界、演示截图、配图、源码构建与便捷安装指引。

## 下载

`AIYOUClean-0.6.2-macOS-arm64.zip`：Apple Silicon，目标 macOS 13+。下载后解压并拖入应用程序；或使用仓库 `scripts/install.sh`。`SHA256SUMS` 用于核对文件完整性。只读 CLI 另行提供。

二进制为本地 ad-hoc 签名，尚无 Apple 公证或 Intel 包。首次打开限制与完整磁盘访问说明见安装指南；不自动绕过系统保护。可选 ClamAV 引擎与病毒库不包含在安装包中。
