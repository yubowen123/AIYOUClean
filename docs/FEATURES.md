# 当前功能与边界

对应 v0.6.2 / build 10；产品入口以 `Sources/CleanRoomCore/ProductFeatures.swift` 为准。

## 检查和整理

| 功能 | 已实现范围 | 需要理解的边界 |
| --- | --- | --- |
| 智能检查 | 启动磁盘逻辑根 `/` + 已挂载本地数据盘；元数据索引、大旧文件、跨目录查重、已知缓存、安全状态与可选应用关联 | 全盘文件检查不是全盘病毒查杀；网络卷、系统辅助挂载和任意快照不自动加入 |
| 本地垃圾清理 | 用户缓存、日志、Xcode DerivedData；也可选择文件夹 | 不把整个用户目录当垃圾；不能完整统计、含忽略内容的父目录不能整体清理 |
| 大文件与旧文件 | 默认至少 100 MB 或一年未修改；按显示范围检查 | 属于候选，不代表文件无用 |
| 重复文件 | 大小分组、完整 SHA-256、身份/内容复核、固定保留一份 | 内容相同也可能被不同工程引用；需核对保留路径 |
| 相似图片候选 | 图片差异哈希 dHash、磁盘分组索引 | 近似候选，不是语义识别；压缩、裁剪等可能漏检 |
| 下载文件 | 显示下载目录文件和安装包 | 不判断某个下载是否还需要 |
| 本地 AI 模型 | Ollama、Hugging Face、LM Studio 等已知本地目录占用 | 是模型文件整理，不推理或调用模型；需核对模型管理器仍在使用的文件 |
| 本地邮件附件 | Mail 下载附件目录 | 受权限和本地下载范围限制，不连接邮箱，不代表邮件服务器存储 |
| 空间导航 | 目录下钻、逻辑量/分配量、硬链接去重、图块聚合 | 不能把逻辑量当 APFS 精确可释放空间；未读取部分明确标记 |
| 应用卸载 | 应用清单与精确 bundle ID 对应的支持文件候选 | 需核对；不以模糊名称匹配任意用户文件 |
| 应用残留 | 没有对应已安装应用的缓存和偏好候选 | 未找到应用不代表文件一定无用 |

## 高级清理和维护

- 开发 / AI 缓存、损坏偏好候选、iOS 本地备份：按支持规则检查，并在处理前确认具体路径。
- 废纸篓：受控清点、独立永久删除确认；永久删除最多一批 2000 个明确的顶层项目，目录内遍历没有旧 5 万节点截止。
- 文稿历史：通过 macOS 文稿版本接口枚举、归档和恢复；不冒充全部系统历史或全盘版本库清空。
- Chrome / Firefox 本地隐私：按配置目录和类别检查，处理前关闭浏览器，先建立 SQLite 备份。下载记录处理不删除下载文件；Cookies 处理可能退出登录。
- 系统安全状态：Gatekeeper、SIP、FileVault、防火墙等只读状态，不自动修改保护。
- 系统维护和监控：明确确认的维护命令、CPU / 内存 / 磁盘 / 进程等本机采样，不承诺自动修复所有系统问题。
- ClamAV：外部引擎检测、病毒库更新入口及隔离恢复；须安装对应命令和病毒库。本次未完成真实引擎/病毒库/病毒样本验收。

## 一次扫描，分批处理

1. SQLite 保存完整结果，界面每页最多 200 项。
2. 普通文件扫描、智能检查、高级候选与废纸篓清点持续到结束、主动取消或真实错误，不因旧数量/时间/结果阈值自动截断。
3. 切页不取消后台工作。检测、清理、恢复、导出、引擎更新和维护在同一应用实例共用一个任务名额。
4. 处理只移除真实成功回执对应的路径和后代，失败及未处理项保留；保留查询/排序/范围/页码，越界才退回最后有效页。
5. 结果在本次应用会话中保存；退出不续扫，不跨版本迁移旧结果。修改范围、忽略规则或重扫仍作废相应旧报告。

## 当前隐藏的能力

云盘/邮箱 OAuth 连接、云存储入口、全量应用更新、登录与后台项目管理、独立系统权限管理、擦屏遮罩。相关后端源码有保留，存在源码不等于产品可用或验证完成。

## 文件访问

“文件与文件夹”可能出现系统询问；完整磁盘访问需手动进入系统设置添加当前 `.app`。应用内“访问权限引导”可复制当前版本和完整 bundle 路径并定位应用。`errno 1/13` 也可能来自 ACL、文件权限或系统保护，不能全归因为缺少完整磁盘访问。

不改 TCC 数据库、不禁用 SIP、不自动获得管理员权限。对某路径无权访问时继续其他可读范围，并保留问题列表。忽略规则保护相应路径及包含它们的父清理候选。
